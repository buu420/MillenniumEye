# Controls

Millennium Eye retains BlindDuel's native UI and input bridge. Use the game's
normal controller/keyboard controls for choosing and confirming actions.
The following shortcuts come from the recovered reader; full live controller
and menu coverage remains unverified for this beta.

During a duel, the unshifted zone shortcuts select your side; hold Shift for
the opponent's side:

| Key | Read / focus |
| --- | --- |
| C | Hand |
| M | First main monster zone |
| S | First spell/trap zone |
| T | Field spell zone |
| G | Graveyard |
| B | Banished pile |
| D | Extra deck |
| L | Life points |
| 1 through 5 | Individual main monster zones |
| 6 / 7 | Your extra monster zones |

Opponent hand and extra-deck shortcuts announce counts while card identities
are hidden. The native visibility gate controls all other identity reads.
**Shift+P** reads the opponent's hand, deck and extra-deck counts together.

**Ctrl+Up/Down** or **right stick Up/Down** moves through current card details.
**F8** cycles the native activation-confirmation toggle; **Ctrl+F8** reads it.
If unavailable, select Switch or Switch+Hold in the game's Duel settings.
Native controller mode changes are announced too.

The inherited Left Alt shortcut clears the card preview. The repaired code
does not force a toggle to become active when the game disables it. In Deck,
the inherited P shortcut reads crafting-point counts; in Shop it reads gems.
