# Millennium Eye 0.1.1 beta verification

**Withdrawn candidate.** This candidate was briefly uploaded, then returned
to draft before manager publication when final research identified an unsafe
inference from private card IDs to earlier hidden movements. Version 0.1.2
removes that inference. The observations below describe the earlier candidate,
not the recommended build.

Date: October 21, 2026.

This maintenance release addresses missing opponent attacks, effect targets
including graveyard cards, and publicly revealed hand additions. The native
binary remains Master Duel 2.8.0 / Steam build 24462996 with the supported
GameAssembly hash listed in VALIDATION.md.

## Offline evidence

- Release build against installed IL2CPP bindings: zero warnings/errors.
- 26 event regressions pass using production hooks, public reveal correlation,
  activation reader and speech policy with native/speech boundary doubles.
  Failures were observed before their corresponding repairs.
- The original 21 reader checks and 25 installation checks pass.
- 77 Harmony patch targets resolve against the installed generated bindings.
- Independent review rechecked the native public-search path, positive hand
  reveal modes, scoped record capture and hand-shuffle invalidation; no
  remaining material finding was reported.

The tests cover multi-card and repeated targets, graveyard locations, explicit
direct/canceled attack markers, hidden identity rejection, reveal/move ordering,
native public searches without a separate reveal, hand mixing boundaries,
stale focus queues, and activation/target/prompt speech ordering.

## Deployment and publication

The installed 0.1.0 reader is recognized for upgrade and backed up by the
standalone installer. The package retains the existing Tolk, NVDA controller
and SDL3 dependencies. Saves and settings remain outside its replacement list.
The deployed DLL SHA-256 is
`65A90A6076C400F66902DF9CF30B8B53B3180A697CAD556AEE0D32D2676D26E6`.
All 18 payload checksums matched after installation, plus the package metadata.
MelonLoader loaded that exact DLL as Millennium Eye 0.1.1, detected NVDA and
registered 20 handlers with no failed-patch entry. Menu speech output appears
in the local log; no new listener confirmation has been claimed.

The game rewrote one opaque LocalSave file during the startup session. Its
meaning is unknown; the pre-launch copy was retained. The installer's owned
file list excludes saves and settings. The game remains available for the
player's testing.

Public package and catalog verification is recorded after publication below.

## Player validation

Live duel response-window timing, audible attack/target/reveal speech and
controller play have not been verified. The player reported that they had not
tried a duel with 0.1.1 yet. Successful package checks or a loader
startup do not establish those behaviors. The release remains a beta.
