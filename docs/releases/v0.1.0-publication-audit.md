RealAmethyst and contributors' BlindDuel. It retains LGPL v3 and begins its
own version sequence at 0.1.0. The GitHub release is a prerelease and the
manager channel is beta.

All four GitHub asset digests/sizes matched local artifacts. Each asset was
then anonymously downloaded and verified. The ordinary anonymous raw catalog
matched the complete committed index and exposed the final beta/hash. The
CLI completed `indexPublished`, `liveVerified` and `directorySubmitted`.
All three prior games and their 174 historical release records were preserved.

The standalone and AMM ZIPs contain the same 19 installed payload files,
including package metadata. The AMM ZIP additionally contains its manifest
and staging-only read-only conflict check. The installed reader uses the
legacy `Mods/BlindDuel.dll` path for replacement without duplicate hooks;
its assembly and loader identity are Millennium Eye 0.1.0.
Reader SHA-256:
`47825D59E103615A9629603BD4DEB870C9A48E3613C75D1BEC4F471BC227781A`.

The manager declares the verified official MelonLoader 0.7.2 x64 ZIP and
Microsoft .NET 6.0.36 x64 Desktop Runtime installer. The runtime check uses
the explicit 6.0.36 registry value, so .NET 8/10 alone cannot satisfy it.
Tolk was built from unchanged published source; the unmodified NVDA 2026.2
controller client and SDL 3.4.0 are included with licenses. Corresponding
Tolk/NVDA source and build instructions are a separate release asset.

Verification passed: zero-warning mod build, 21 reader regressions, 25
temporary-folder installation checks, 72 resolved Harmony targets, GitHub
CI and AMM parser validation. Independent review checked the final AMM ZIP,
all payload hashes, dependency pins and launcher exclusion. Review findings
were fixed with failing-then-passing tests for renamed duplicate readers and
resuming an interrupted restore.

The exact released DLL and native libraries loaded through Steam in Master
Duel 2.8.0. NVDA detection and 20 registered menu handlers were logged without
failed patches. The player confirmed audible title-screen and card/menu speech.
No automated Confirm or duel action was used for this validation.

Before startup, current LocalSave/UserData files were copied to a private
backup. Deployment preserved all 11 tracked pre-existing save/settings files.
During subsequent startup/player menu use, one opaque LocalSave file changed;
its semantics are unknown. Ten other tracked files remained unchanged.
No claim is made that all saves stayed byte-identical through native gameplay.
Owned-file rollback backups remain under `UserData/MillenniumEye/Backups`.
Private logs, saves, account identifiers, game binaries and generated game
bindings are excluded from the public source and release assets.

Remaining validation: fresh-machine installation through the manager UI,
live duel counts/stats, stale-effect transitions, public search announcements,
controller play and draw/standby activation timing. Successful source/package
checks and audible menu speech do not establish those cases.
